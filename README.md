# Sovol_ZERO_custom_config
A modular set of .cfg files that replaces the stock config.cfg. Written from scratch, it adds features like filament-dependent nozzle wipe and cooldown temperatures and makes parameter tuning simpler. It also removes buggy or poorly written Sovol macros. In particular, START_PRINT is improved: the stock macro can produce an incorrect Z-offset because filament oozes after the nozzle wipe and before contact probing.
